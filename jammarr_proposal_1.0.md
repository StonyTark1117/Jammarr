  # Jammarr: Synchronized Plex Music for Minecraft                                                                                                                                                                                                                                                                
                                                                                                                                                                                                                                                                                                                  
  ## Summary                                                                                                                                                                                                                                                                                                      
                                                                                                                                                                                                                                                                                                                  
  This is feasible, but not as a server-only mod. Vanilla clients can only play known sound resources; dynamically decoded Plex audio requires client-side playback code. Jammarr should therefore ship as one required NeoForge mod installed on both the dedicated server and every client. NeoForge supports   
  synchronized custom payloads between those sides, while Minecraft’s actual audio engine exists only on the client. NeoForge networking (https://docs.neoforged.net/docs/1.21.4/networking/payload/), NeoForge sides (https://docs.neoforged.net/docs/1.21.1/concepts/sides/)                                    
                                                                                                                                                                                                                                                                                                                  
  The server will remain authoritative for Plex access, the global queue, and playback position. It will fetch each track once from Plex, relay compressed audio through the existing Minecraft connection, and never expose the Plex token to players. Plex supports authenticated JSON APIs and                 
  client-selected music transcode profiles. Plex API (https://developer.plex.tv/pms/), Plex token guidance (https://support.plex.tv/articles/204059436-finding-an-authentication-token-x-plex-token/)                                                                                                             
                                                                                                                                                                                                                                                                                                                  
  ## Architecture and Behavior                                                                                                                                                                                                                                                                                    
                                                                                                                                                                                                                                                                                                                  
  - Replace the generated example content with clearly separated common, server, and client code.                                                                                                                                                                                                                 
  - Server-side Plex service:                                                                                                                                                                                                                                                                                     
      - Read the base URL, token, and music-library key/title from config/jammarr-server.toml.                                                                                                                                                                                                                    
      - Allow JAMMARR_PLEX_TOKEN to override the file token so secrets need not be stored on disk.                                                                                                                                                                                                                
      - Validate the connection and selected music library at startup/reload; redact tokens from all logs and errors.                                                                                                                                                                                             
      - Browse/search artists, albums, audio playlists, and tracks through paginated Plex JSON requests.                                                                                                                                                                                                          
      - Expand albums and playlists into track snapshots when queued.                                                                                                                                                                                                                                             
                                                                                                                                                                                                                                                                                                                  
  - Global player:                                                                                                                                                                                                                                                                                                
      - Maintain one queue across all dimensions.                                                                                                                                                                                                                                                                 
      - Automatically prepare and start the first queued item.                                                                                                                                                                                                                                                    
      - Allow every player to browse and append tracks.                                                                                                                                                                                                                                                           
      - Restrict pause, resume, skip, clear, remove, and reorder to operators with vanilla permission level 2.                                                                                                                                                                                                    
      - Rate-limit browse and queue requests and cap the queue at 500 entries.                                                                                                                                                                                                                                    
      - Pause when no players are online by default and resume when the first player joins.                                                                                                                                                                                                                       
                                                                                                                                                                                                                                                                                                                  
  - Audio preparation and transport:                                                                                                                                                                                                                                                                              
      - Request a constant-bitrate 160-kbps stereo MP3 rendition from Plex’s universal music transcoder; no external FFmpeg installation will be required.                                                                                                                                                        
      - Download and validate each rendition into an atomic server cache before announcing playback, prefetching the next track while the current track plays.                                                                                                                                                    
      - Bound the cache to 1 GiB by default with LRU eviction, while pinning the current and next tracks.                                                                                                                                                                                                         
      - Split MP3 data on frame boundaries into payloads no larger than 16 KiB.                                                                                                                                                                                                                                   
      - Use a pull/window protocol with sequence numbers, presentation timestamps, hashes, acknowledgements, and approximately five seconds of client buffering. Audio bytes must not travel in control packets.                                                                                                  
      - Schedule new tracks several seconds in the future against an estimated server clock. Late joiners request the frame nearest the authoritative current position.                                                                                                                                           
      - Broadcast periodic state corrections; clients farther than 500 ms out of sync rebuffer and seek. Target normal synchronization within approximately 250 ms, while treating severe network congestion as best-effort rather than guaranteeing sample-perfect playback.                                     
                                                                                                                                                                                                                                                                                                                  
  - Client playback:                                                                                                                                                                                                                                                                                              
      - Bundle an MP3 decoder such as LGPL JLayer and retain its required license notices.                                                                                                                                                                                                                        
      - Feed decoded stereo PCM into Minecraft’s existing LWJGL/OpenAL sound thread through a narrowly scoped streaming-audio integration.                                                                                                                                                                        
      - Treat the stream as background music: apply both Master and Music volume controls, suppress vanilla background music only while Jammarr is actively playing, and restore normal music afterward.                                                                                                          
      - Default each player to listening, with persistent local enable/mute and Jammarr volume controls. Local opt-out does not alter the global queue.                                                                                                                                                           
      - Stop and release buffers cleanly on disconnect, world change, resource reload, audio-device reset, or server stop.                                                                                                                                                                                        
                                                                                                                                                                                                                                                                                                                  
  ## User Interfaces and Persistence                                                                                                                                                                                                                                                                              
                                                                                                                                                                                                                                                                                                                  
  - Bind a configurable key, default P, and provide /jammarr to open a custom music screen.                                                                                                                                                                                                                          
  - Screen views: Now Playing, Search, Artists, Albums, Playlists, and Queue. Results are server-paginated; selecting a track queues it, while selecting an album or playlist offers “queue all.”                                                                                                                 
  - Show preparation, buffering, paused, Plex-offline, and permission-denied states without revealing server details or tokens.                                                                                                                                                                                   
  - Provide /jammarr status for everyone and operator commands for reload, pause/resume, skip, clear, cache statistics, and connection diagnostics.                                                                                                                                                                  
  - Define versioned payload families for:                                                                                                                                                                                                                                                                        
      - capability/time synchronization;                                                                                                                                                                                                                                                                          
      - browse request/results;                                                                                                                                                                                                                                                                                   
      - queue snapshots and mutations;                                                                                                                                                                                                                                                                            
      - playback manifest/state;                                                                                                                                                                                                                                                                                  
      - audio chunk request/data/acknowledgement;                                                                                                                                                                                                                                                                 
      - structured, sanitized errors.                                                                                                                                                                                                                                                                             
                                                                                                                                                                                                                                                                                                                  
  - Persist stable Plex rating keys, queue order, current item, state, and playback checkpoint in server saved data.                                                                                                                                                                                              
  - Expose restartMode with:                                                                                                                                                                                                                                                                                      
      - RESTART_TRACK as the default: preserve the queue but restart the current song;                                                                                                                                                                                                                            
      - CLEAR: discard playback state;                                                                                                                                                                                                                                                                            
      - RESUME_POSITION: resume from the last five-second checkpoint, or the exact graceful-shutdown position when available.                                                                                                                                                                                     
                                                                                                                                                                                                                                                                                                                  
  - Missing Plex items are logged and skipped during restoration. Jammarr does not modify Plex ratings, play history, or playlists in v1.                                                                                                                                                                         
                                                                                                                                                                                                                                                                                                                  
  ## Failure Handling and Test Plan                                                                                                                                                                                                                                                                               
                                                                                                                                                                                                                                                                                                                  
  - Authentication or configuration failure disables Plex operations without crashing the Minecraft server and gives operators an actionable diagnostic.                                                                                                                                                          
  - A failed track preparation retries three times with backoff, then skips that item and continues the queue. An already cached current track continues through a temporary Plex outage.                                                                                                                         
  - Clients that cannot maintain the minimum buffer rebuffer locally rather than delaying every listener.                                                                                                                                                                                                         
  - Require the same Jammarr network protocol version on server and client; unmodded or incompatible clients are rejected with a clear message.                                                                                                                                                                   
  - Automated tests:                                                                                                                                                                                                                                                                                              
      - Fake-Plex HTTP tests for authentication, library selection, pagination, search, playlists, malformed metadata, timeouts, and transcode failures.                                                                                                                                                          
      - Queue permissions, rate limits, persistence, all restart modes, missing-item recovery, and empty-server pausing.                                                                                                                                                                                          
      - MP3 validation, frame-aligned chunking, cache eviction, acknowledgements, retransmission, and bounded per-client buffering.                                                                                                                                                                               
      - Deterministic clock-offset, late-join, pause/resume, and drift-correction tests.                                                                                                                                                                                                                          
      - Dedicated-server classloading test proving client/OpenAL classes never load server-side.                                                                                                                                                                                                                  
                                                                                                                                                                                                                                                                                                                  
  - Integration acceptance:                                                                                                                                                                                                                                                                                       
      - Run test, GameTest server, dedicated-server startup, client startup, and the production build.                                                                                                                                                                                                            
      - Connect two clients, verify they hear the same track within the synchronization target, then test late join, opt-out, reconnect, skip, pause/resume, and track transition.                                                                                                                                
      - Simulate latency, dropped chunks, Plex downtime, invalid credentials, cache pressure, restart restoration, and an audio-device reload.                                                                                                                                                                    
      - Confirm approximately 20 KB/s of audio payload per active listener at the default bitrate, plus modest protocol overhead, through a multi-client soak test.                                                                                                                                               
      - Before release, validate browsing and one complete MP3 transcode against the intended live Plex Media Server version because Plex transcoder behavior can differ between server releases.                                                                                                                 
                                                                                                                                                                                                                                                                                                                  
  ## Assumptions                                                                                                                                                                                                                                                                                                  
                                                                                                                                                                                                                                                                                                                  
  - Target the repository’s current Minecraft 1.21.1, NeoForge 21.1, and Java 21 baseline.                                                                                                                                                                                                                        
  - Ship one JAR required on both server and clients; a genuinely dynamic Plex implementation will not offer a server-only fallback.                                                                                                                                                                              
  - Use text metadata in the first release; album-art transfer is deferred to avoid unnecessary bandwidth and cache complexity.                                                                                                                                                                                   
  - HTTPS uses normal certificate validation. Plain HTTP remains allowed for private-network Plex installations but emits a warning.                                                                                                                                                                              
  - The existing starter currently builds successfully; implementation will also remove its deprecated example registrations and warnings.
